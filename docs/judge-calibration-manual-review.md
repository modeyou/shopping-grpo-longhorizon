# Judge 校准集人工确认表（v1）

## 目的

这份表只用于确认 30 条 Judge 校准集中无法完全由代码断言的 9 条样本，
不是让人工重新评价完整轨迹。确认内容分为三类：

1. **Rubric 是否忠实于用户需求**：有没有写错、遗漏或加入用户没有要求的条件。
2. **Judge 状态是否有轨迹证据**：`satisfied`、`violated`、`unknown` 是否合理。
3. **是否可以归因给 Agent 决策**：Actor 未见的隐藏需求可以用于终局审计，但不能用于评价其过程决策。

原 Final-200 Rubric 和旧 Judge 输出不做原地修改。人工确认后，修订项应生成新的
校准 Rubric 版本；旧结果继续保留为历史诊断证据。

## 建议结论

### task 2240 — 二级建造师教材

- 用户目标：2025 年二级建造师建筑全科官方用书，最好含真题，价格不高于约 230 元。
- 当前问题：Rubric `r0001` 写成了“全国一级建造师考试”；最终商品只是二建建筑实务点题资料，也未充分证明“全科官方用书 + 真题”。
- 建议：**修改 Rubric**。将“一级”改为“二级”，并补齐全科、官方用书、真题等真实要求；当前购买不能据此直接判为完全满足。

### task 4479 — 羊奶粉 400g × 2

- 用户目标：荷兰进口、高钙富硒羊奶粉，400g 每罐，共 2 罐，约 400 元。
- 轨迹商品：`高钙富硒400g*2罐`，396 元。
- 当前问题：Rubric `r0007` 把规格写成“高钙富硒 800g”，与“400g × 2 罐”混为一谈。
- 建议：**修改 Rubric**。规格应表达为“400g/罐且 2 罐”，不能要求单件选项为 800g；该轨迹在规格和价格上满足。

### task 14960 — 小型犬蓝色蓬蓬裙

- 用户目标：小型犬、蓝色蓬蓬裙、选择最小尺码，价格不高于约 18 元。
- 轨迹商品：蓝色无袖款、S 码，16 元。
- 当前问题：Rubric `r0003` 将“最小尺码”的期望值写为 XXL。
- 建议：**修改 Rubric**。期望应为商品可选尺码中的最小码（本轨迹为 S），当前购买满足。

### task 973 — 深蓝色夏季正式套装

- 用户目标：适合炎热季节、轻薄有质感、正式、深蓝色，约 300 元，适合 90 斤以下。
- 轨迹商品：蓝色西装套装、S 码，296 元。
- 当前问题：Rubric 使用“职业女裤套装”和“藏蓝色短袖西装”等偏向 Gold 商品的精确描述，强于用户原始语义。
- 建议：**修改 Rubric**。类别改为正式套装，颜色按深蓝语义判断，不强制特定 Gold 标题；修订后该商品可作为合理替代品继续核验材质和季节属性。

### task 2057 — 汽车出风口维修件

- 用户目标：叶片摆风、支架、连杆修复、卡扣，并包含全车软条 12 条；还涉及车型适配。
- 轨迹商品：对应维修配件，选择 2010–2014 皇冠车型和软条 12 条。
- 当前问题：冻结 Query/Rubric 遗漏软条数量和车型信息，类别还写成“空调旋钮”，部分描述像目标商品文案而非用户要求。
- 建议：**修改 Rubric**。类别改为出风口维修配件，并只依据可追溯的用户需求补入软条数量和车型适配；当前旧 Rubric 不用于发布结论。

### task 7126 — 黑色短袖保暖打底衫

- 用户目标：黑色、短袖、薄款，L 码（120–140 斤），约 15 元。
- 轨迹商品：15 元，最终选择 L 码；终局选项没有颜色轴。
- 当前问题：商品标题可能支持部分属性，但最终选择中没有可验证的黑色选项，不能仅凭推测判满足。
- 建议：**保留 Rubric**；L 码和价格判 `satisfied`，黑色相关要求判 `unknown`，除非轨迹中另有可靠商品证据。

### task 7153 — 俄罗斯进口蜂蜜味伏特加

- 用户目标：俄罗斯原装进口、40 度、约 1L、蜂蜜味、适合调酒和送礼，约 270 元。
- 轨迹商品：原装进口，1000ml 蜂蜜原味，268 元；标题和选项覆盖主要要求。
- 当前问题：Reward 只给了部分替代，但 Judge 认为要求均满足。
- 建议：**保留 Rubric，认可 Judge 的满足判断**。Reward–Rubric 分歧单独进入 Reward 审计，不能反过来强制 Judge 跟随 Reward。

### task 14412 — 隐藏的黑色要求

- 完整目标包含黑色和约 10 元，但 Actor 当轮可见请求没有提供黑色要求。
- 轨迹商品：红色，12 元；Judge 将黑色要求判为 `violated`。
- 建议：**保留 Rubric 和终局 `violated`**；但该隐藏条件不得用于降低 Agent 的过程决策/需求遵循评分，只能作为终局完整目标审计。

### task 18004 — 可定制可丽耐淋浴底盘

- 用户目标：一体式可丽耐浴室底盘、防滑排水、支持定制尺寸，约 3500 元。
- 轨迹商品：可定制可丽耐淋浴底盘，3800 元。
- 当前问题：Rubric `r0007` 添加了用户未要求的“岩板底座”，同时遗漏约 3500 元的预算条件；不同轨迹的 Judge 对“支持定制”判断也不一致。
- 建议：**修改 Rubric**。删除“岩板底座”，增加软预算要求；标题可证明“支持定制”能力，但是否实际选定用户需要的尺寸应为 `unknown`（没有具体尺寸执行证据）。
